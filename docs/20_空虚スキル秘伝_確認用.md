# 空虚スキル秘伝 追加データ確認用

## 編集方法

このファイルの表を直接修正してください。効果・デメリット・確率・確認欄を編集できます。
IDは候補を区別する固定番号です。同じ効果でもデメリットが違う候補は別行です。
複数効果は「／」で区切っています。「なし」はデメリットなしです。
確率は百分率で、抽選元「未確認の空虚スキル秘伝」全体に対する確率です。
確認欄は「未確認」「要確認」「確認済」を使用してください。確認済への変更は人間が行います。

編集後、次のコマンドで確認用JSONを再生成できます（本番ファイルは書き換えません）。

```sh
node scripts/export_void_sigil_review.mjs
```

出力先: `docs/data/void-sigil.review.json`

JSONは候補単位の追加データです。既存の `src/game-rules/skill-sigil.json` へそのまま
上書きする形式ではありません。現行形式では複合効果・デメリット・確率を保持できないため、
組み込み済みの正本は `src/game-rules/skill-sigil.json` です。
確認後の再反映には `node scripts/apply_void_sigil.mjs` を使います。
全行が「確認」または「確認済」の場合のみ反映します。
空虚は1行=1固定候補（効果・数値・デメリットを含む）で、既存等級のIDとデータは保持します。

以下は確認時の注意事項の記録です。全62行の「確認」と2026-10-30の反映依頼を受け、
F17も表に記載された文言で反映しました。

1. 無欠F17: 提供画像・韓国確率表は対象に「冒険者から受けるダメージ−10%」を付与する表現。
   Global更新記事は対象の対冒険者ダメージ軽減を低下させる表現です。意味が逆になる可能性があり、
   ここでは提供画像の表記を保持しています。日本版ゲーム内の文言で確定してください。
2. 無欠の系列軽減低下は「敵の被系列ダメージ軽減効果を低下」する効果です。
   自身の系列ダメージ低下や敵への直接ダメージと混同しないでください。
3. デメリットの被ダメージ増加は「スキル使用時、3秒間、スキル使用中に冒険者から受ける最終ダメージ量+6%」。
   表ではこの条件を省略せず記載しています。
4. 既存等級の誤記修正、家門共有対応、製作・分解・自動装着ルール変更は今回のデータには含めません。
5. 提供画像で「命中時」と記載されたものは命中時として保持。既存の「使用時」表記へ機械的に寄せません。
