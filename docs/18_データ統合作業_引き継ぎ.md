## この作業の目的

30クラス分バラバラだったデータ (旧マスタExcel 1本 + 説明Excel 30本 + 画像フォルダ) を、
**統合Excel 2本** にまとめ、そこからJSONを生成するパイプラインへ切り替える。
最終目標は「1つのExcelを開けばそのクラスの全データが見られる」状態にし、
元の30ファイルとの紐づけを切ること。

まなの3ステップ指示:
1. 統合Excel → JSON生成スクリプトを新規に書く
2. 生成JSONが今のHPと同じ見た目になる (+意図した変更だけ反映される) ことを確認する
3. 確認できたら、元の30ファイル・旧マスタExcelとの依存を切る

## 新しい正本 (入力データ)

`資料/クラスデータ/` (このフォルダがこれからの入力の正本。**生成スクリプトで上書きしないこと**)

### 黒い砂漠M_スキル・パッシブ.xlsx (32シート)

| シート | 内容 |
| :---- | :---- |
| クラス一覧 | コード / クラス名 / 表示順 / 有効 (30行) |
| パッシブ一覧 | 横=クラス、縦=パッシブ①②。セルは `[日本語 / 韓国語 / 英語]` のヘッダー行 + 本文 |
| スキル_{CODE} ×30 | 1行=1スキル (18行: 通常13 + ラバム4 + 闇精霊の怒り1) |

スキルシートの列順 (まな指定):

```
skill_id / 種別 / 表示番号 / 名前(日本語) / 区分 / STACK / CT / HIT /
説明(日本語) / 装着可能秘伝 / 秘伝装着可否 / 画像パス(自動検出・参考) /
名前(韓国語) / 名前(英語)
```

- **区分**: `PvE` / `PvP` / `PvE・PvP`
- **STACK** = 最大使用回数、**CT** = 再使用待機時間、**HIT** = 最大〇打撃。
  HP側では `STACK:2　CT:4　HIT×2` の形式で表示する (説明本文からは分離済み)
- **装着可能秘伝**: 日本語表記の「・」区切り (例 `系列・無欠・鮮明・整った`)。
  JSON側では `branch` 等の英語idに戻す (`src/game-rules/skill-sigil.json` が対応表)
- **画像パス**: 生成時に自動検出して埋める参考列。手入力不要

### 黒い砂漠M_プロフィール.xlsx (30シート)

`プロフィール_{CODE}`。A列ラベル (名前 / 出身地 / Other / エピソード)、B列に値。
Other・エピソードは現在全クラス空欄 (エピソードは今後追加予定の枠)。

### 途中で見つけて直したバグ

統合Excelを作った際、HIT値の抽出が緩く「・スキルボタン長押しで最大2打撃」のような
**条件付きの行を丸ごと消してしまい、「長押しで」等の条件が失われていた (67件)**。
まな判断により **行は説明に戻し、HIT値も残す** 方針で復元済み。

### まなが決めた仕様 (2026-08-03〜04)

1. **HIT抽出は位置で決める**: 「最大使用回数 → 再使用待機時間 → 最大〇打撃」と並ぶ、
   その**直後の1行だけ**。説明の後ろに出てくる「最大〇打撃」は本文にそのまま残す
2. **条件付きHIT行**: 説明に行を戻し、かつ HIT値も表示する
   (打撃数が2箇所に出るが、行側は「どうすればその打撃数になるか」の説明になる)
3. **「最大〇ヒット」も「最大〇打撃」と同じ扱い** (古い言い回しのクラスが残っているため)
4. **ラバム技術チップ**: sp_1〜sp_4 は全てラバムスキルなので、**120件全部にチップを出す**
   (旧データは元Excelのタグ行の入力ブレで120件中24件しか出ていなかった)

### HIT抽出の取りこぼし修正 (2026-08-04)

抽出が「最大〇**打撃**」しか見ておらず、「最大〇**ヒット**」と書かれた行を拾えていなかった
(8クラス・76件)。まな指示により打撃と同じ扱いにして補完。
単独行43件は説明から数値化、条件付き33件は行を残したままHIT値を設定。

修正後の検証結果:

| 項目 | 結果 |
| :---- | :---- |
| HITの位置ルール違反 | 0件 |
| HITの取りこぼし | 0件 |
| 説明行の欠損 | 0件 (※) |
| 説明途中の「最大〇打撃」が保持 | 99件 |
| 条件付きHIT行が説明に保持 | 85件 |

※ 1件だけ検出されたが、旧データが1配列要素に改行を含んでいたのが分割されただけで
文字列としては同一 (`white-space: pre-wrap` のため表示も同じ)。
