コミット前の落とし穴

手元で npm run build を回すと画像同期が走り、repo外の正本から消えた画像を public/画像/ からも削除する。Cloudflare側は public/画像/ をそのまま配信するので、意図しない画像削除がそのまま本番に出る。コミット前に git restore -- "public/画像" を通すこと。
