# Skill Sigil Data Editor

公開サイトとは独立した、管理者用のデスクトップ編集アプリです。公開サイトの画面やルーティングには組み込まれません。

## 起動（Windows）

初回だけこのフォルダで `npm install` を実行し、その後は `start-editor.bat` を開きます。

## 起動（Mac）

`start-editor.command` を開きます。初回はMac用ファイルを自動で準備してから起動します。
macOSにNode.jsが入っていない場合は、先にNode.jsのLTS版をインストールしてください。

Windowsで作成した `node_modules` はMacでは利用できません。外付けSSDをWindowsとMacで
共用する場合、OSを切り替えた最初の起動時にMac用ファイルを自動で準備し直します。

どちらのOSでも、ターミナルから `npm run editor` を実行して起動することもできます。

## クラス画像

編集画面上部の「画像プレビュー」で、選択中クラスのスキル・パッシブを1枚にまとめたレイアウトを確認できます。プレビューは見渡しやすい65%で開き、スクロールバーと右上の「−／＋」で表示位置・倍率を調整できます。「PNG保存」を押すと、スクロールバーや倍率ボタンを含めず、同じ内容を高解像度PNGとして保存します。

文字・数値の入力欄は入力方式を固定せず、Windowsで現在選ばれている日本語／英語入力をそのまま引き継ぎます。数値欄の内容チェックは保存時に行います。

- 選択中のスキルは保存前の入力内容も反映します。
- その他のスキルはサイト用データとExcel由来の名称・STACKを使用します。
- PNG保存はローカル処理で、サイトへの公開は行いません。
- スキルアイコンは現在のテンプレート仕様どおり空欄です。

## データ

- 読み込み・保存先: `../src/data/master.json`、`../src/data/descriptions.json`
- Excel原本: `../資料/クラスデータ/`（参照用として変更しません）
- 「サイトへ公開」: テストとビルドの成功後、データファイルだけをGitへコミットしてpushします

サイト本体のソースコードは変更せず、サイトがすでに利用しているJSONだけを更新します。
