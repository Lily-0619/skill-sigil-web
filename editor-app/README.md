# Skill Sigil Data Editor

公開サイトとは独立した、管理者用のデスクトップ編集アプリです。公開サイトの画面やルーティングには組み込まれません。

## 起動

初回だけこのフォルダで `npm install` を実行し、その後は `start-editor.bat` を開きます。

## データ

- 読み込み・保存先: `../src/data/master.json`、`../src/data/descriptions.json`
- Excel原本: `../資料/クラスデータ/`（参照用として変更しません）
- 「サイトへ公開」: テストとビルドの成功後、データファイルだけをGitへコミットしてpushします

サイト本体のソースコードは変更せず、サイトがすでに利用しているJSONだけを更新します。
